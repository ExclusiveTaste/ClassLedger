# ClassLedger 学生课时管理系统

ClassLedger 是一个供老师个人使用的本地学生课时管理系统，用于替代传统 Excel 课时表。

系统采用单文件结构，只需双击 `index.html` 即可在 Chrome、Edge 等现代浏览器中使用。所有正式功能均使用 HTML、CSS 和原生 JavaScript 实现，不需要服务器、数据库、Node.js、外部框架、CDN 或网络连接。

## 快速开始

1. 保持项目文件位于同一文件夹中。
2. 双击 `index.html`。
3. 选择 Chrome 或 Edge 打开。
4. 先在“上课时间管理”中建立固定时段。
5. 在“学生管理”中添加学生并设置初始课时。
6. 进入“全部记录”，选择记录类型后新增课时变化记录。
7. 返回“课时总表”查看月度明细，或筛选上课时间后批量扣课。
8. 点击学生姓名或“详情”查看完整统计与个人历史记录。
9. 定期进入“数据管理”导出完整 JSON 备份。

不需要执行安装命令，也不需要启动本地服务器。

> 数据保存在当前浏览器的 `localStorage` 中。更换浏览器、浏览器配置或文件位置时，可能使用不同的本地存储空间；可使用“数据管理”的导出和导入功能迁移或恢复完整数据。

## 阶段三使用说明

### 全部记录

“全部记录”页面包含五个标签：

- 正常上课：扣除学生课时
- 续费：分别增加购买课时和赠送课时
- 转介绍：增加赠送课时
- 比赛：扣除比赛课时
- 退费：分别扣除退回购买课时和取消赠送课时

选择标签后点击右侧新增按钮即可创建对应记录。每行提供编辑和删除操作，删除前必须再次确认。

正常上课记录如果与已有记录的学生和日期相同，第一次保存只会显示提示；再次点击“仍然保存”才会真正写入，两条记录不会自动合并。

### 剩余课时

学生管理列表中的“剩余课时”为只读计算结果：

```text
剩余课时
= 初始课时
+ 续费购买课时
+ 续费赠送课时
+ 转介绍赠送课时
- 正常上课扣课
- 比赛扣课
- 退回购买课时
- 取消赠送课时
```

剩余课时不会保存为可编辑字段。新增、编辑或删除记录后，系统会依据全部历史记录重新计算。

## 阶段四使用说明

### 月度课时总表

课时总表默认显示在读学生和当前月份。上课时间、学生状态和姓名搜索只筛选学生行；月份选择只切换正常上课日期列。

同一学生在同一天存在多条正常上课记录时，日期单元格显示扣课合计。比赛、转介绍、续费摘要和剩余课时始终读取全部历史数据，不随月份变化。点击对应历史摘要可以查看完整记录。

顶部“本月扣课”和“本月续费”按浏览器当前自然月统计，因此切换表格月份不会改变统计卡片。

### 批量扣课

1. 使用“上课时间”筛选目标班级或时段。
2. 勾选需要扣课的在读学生，也可以使用表头复选框全选当前可见学生。
3. 点击“批量扣课”，填写日期、每人扣除课时和备注。
4. 确认后系统会为每名学生分别生成一条正常上课记录。

冻课和流失学生不能参与批量扣课。如果某些学生在所选日期已有正常上课记录，系统会先提示重复学生，只有再次确认才会继续保存。

## 阶段五使用说明

### 学生详情

在课时总表、学生管理或全部记录中点击学生姓名即可打开学生详情。详情顶部显示基本信息、购买与赠送课时、各类扣课、退费分项和自动计算的剩余课时。

详情包含五个记录标签。正常上课记录默认查看当前月份，可单独切换月份；续费、转介绍、比赛和退费始终显示全部历史。每条记录均可编辑或删除，操作结束后会返回原学生、原标签和原月份。

点击课时总表中的比赛、转介绍或续费摘要，会直接打开该学生详情的对应标签。详情右上角可以编辑学生或为当前学生添加任意一种记录。

### 全部记录筛选

全部记录页面支持按学生、学生当前上课时间、开始日期、结束日期和备注关键词组合筛选。日期范围包含起止当天，开始日期不能晚于结束日期。

历史记录本身没有保存时段快照，因此上课时间筛选使用学生当前分配的时段。学生未分配、原时段已删除或关联学生不存在时，记录归入“未分配上课时间”；孤立旧记录还可以通过“未知学生（兼容记录）”查看。

## 阶段六使用说明

### 导出完整备份

进入“数据管理”并点击“导出完整 JSON”。浏览器会下载名称类似 `学生课时数据备份_2026-07-31.json` 的文件，其中包含上课时间、学生、五类历史记录和兼容未知字段。导出操作不会修改当前数据。

### 导入并恢复

1. 点击“选择 JSON 文件”并选择以前导出的备份。
2. 系统先在内存中检查 JSON 和核心数据结构，不会立即覆盖当前数据。
3. 核对确认弹窗中的文件名、学生数量和历史记录数量。
4. 点击“覆盖并导入”后，系统才会一次性写入完整数据并重新计算全部余额。

文件无效、校验失败、取消确认或浏览器写入失败时，当前数据保持不变。缺失集合会按兼容规则补为空数组，旧数字字符串、孤立关联和未知字段继续保留。

### 清空数据

点击“清空全部数据”后，必须在危险确认弹窗中准确输入“确认清空”。成功后系统保存 V4.0 空结构，页面会显示真实空数据状态。清空不可恢复，建议操作前先导出备份。

## 本地数据

存储键名：

```text
studentHoursManagerData
```

基础结构：

```javascript
{
  version: "4.0",
  classTimes: [],
  students: [],
  lessonRecords: [],
  renewalRecords: [],
  referralRecords: [],
  competitionRecords: [],
  refundRecords: []
}
```

五类记录字段：

```javascript
// 正常上课
{ id, studentId, date, hours, note }

// 续费：购买和赠送分开
{ id, studentId, date, purchasedHours, giftHours, note }

// 转介绍
{ id, studentId, date, giftHours, note }

// 比赛
{ id, studentId, date, hours, note }

// 退费：购买和赠送分开
{ id, studentId, date, refundedPurchasedHours, cancelledGiftHours, note }
```

数据原则：

- 页面启动时不得自动清空或覆盖已有数据。
- 旧数据结构必须兼容读取并保留已有记录和未知字段。
- 所有新增、编辑和删除只有在成功写入后才更新界面。
- 导入必须先完成解析和格式校验，确认并写入成功后才替换当前数据。
- 清空必须输入“确认清空”，并保存标准空结构而不是直接删除存储键。
- 购买课时和赠送课时必须分开保存。
- 剩余课时只能根据全部历史记录计算，不能直接修改或存储。
- 月份筛选只影响正常上课日期列。
- 比赛、转介绍和续费始终显示全部历史记录。

## 技术与界面约束

- 所有正式功能代码放在 `index.html` 中。
- 只使用 HTML、CSS 和原生 JavaScript。
- 不使用后端、数据库、Node.js、外部框架、CDN 或联网资源。
- 不开发登录、账号、头像、老师姓名、通知和权限功能。
- 使用深绿色主色、白色背景、浅灰边框、轻圆角和大量留白。
- 删除、清空和覆盖导入操作必须二次确认。
- 所有数字输入必须校验。
